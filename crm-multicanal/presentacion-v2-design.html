El Problema

Tienes un negocio con inversión en TikTok Ads pero tu pipeline de ventas está fragmentado: leads en múltiples plataformas, seguimiento manual, pérdida de conversiones.

Dispersión de Leads

Leads llegan por TikTok pero no hay sistema centralizado de seguimiento.

Seguimiento Manual

Tu equipo maneja leads en WhatsApp sin flujo estructurado ni histórico.

Pérdida de Conversiones

Sin automatización, se pierden leads por delays y falta de seguimiento consistente.

Costos Ocultos

Herramientas CRM tradicionales cuestan $100-500/mes sin flexibilidad.

La Solución

Un sistema automático que convierte leads de TikTok Ads directamente a WhatsApp Personal con seguimiento integrado, sin intermediarios, sin costos mensuales recurrentes.

CRM Multicanal: Conversión Automática + Seguimiento Centralizado

API centralizada que conecta TikTok Ads → Supabase → WhatsApp Personal API, con dashboards de seguimiento, asignación de asesores, y reportes de ROI en tiempo real.

Flujo del Sistema

1

Lead Generado

Usuario hace clic en CTA de TikTok Ads, rellena formulario captcha.

2

Webhook Recibido

TikTok envía datos a API central. Validación HMAC-SHA256 por seguridad.

3

Almacenamiento

Lead guardado en Supabase con timestamp, fuente, datos de contacto.

4

Asignación Inteligente

Sistema asigna lead a asesor disponible o cola de espera.

5

WhatsApp Automático

Mensaje inicial enviado a cliente por WhatsApp Personal (Baileys).

6

Seguimiento

Asesor continúa conversación. Dashboard registra interacciones y cierre.

Arquitectura Técnica

Frontend

  • Next.js para dashboard de asesores
  • Tailwind CSS para UI responsiva
  • Vercel para deployment automático

Backend

  • Express.js (Node.js) para API
  • Webhooks TikTok Ads → /api/tiktok/leads
  • Rate limiting, validación HMAC, JWT auth
  • Render.com o Railway para hosting gratis/barato

Base de Datos

  • Supabase PostgreSQL (tier gratis soporta 500K lineas)
  • Row Level Security (RLS) para permisos por asesor
  • Backup automático, replicación

Integración WhatsApp

  • Baileys (WhatsApp API no-oficial para múltiples instancias)
  • O WhatsApp Business API oficial ($100-200/mes si creces)
  • Manejo de sesiones, rate limiting por asesor

Monitoreo & Logs

  • Sentry para error tracking
  • LogRocket para sesiones de usuario
  • Health checks diarios a webhooks

Preguntas Frecuentes

¿Puedo empezar con Baileys y migrar a WhatsApp Business API después?

Sí. La arquitectura está diseñada para ser agnóstica. Starts con Baileys (gratis), migra a WhatsApp API oficial cuando necesites escala sin cambiar tu backend.

¿Qué pasa si TikTok cambia su API de webhooks?

La arquitectura es agnóstica a la fuente de leads. Si cambios, solo actualizas el endpoint receptor. El resto del sistema (asignación, WhatsApp, dashboard) permanece intacto.

¿Puedo agregar más canales después (Google Ads, Meta Ads)?

Sí. El nombre "Multicanal" es literal. Diseñamos para que agregues nuevas fuentes sin reescribir código. Agregar canal = 1-2 días de desarrollo.

¿Es seguro guardar datos de clientes en Supabase?

Sí. Supabase es PostgreSQL hospedado con encriptación en tránsito, backups automáticos, y RLS para control de acceso. Cumple GDPR estándar.
