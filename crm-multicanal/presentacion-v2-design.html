La Solución

El Problema

Campañas en TikTok Ads generan conversiones pero los mensajes llegan dispersos. No hay asignación clara de quién responde. El costo de atender es alto si usas APIs pagadas para cada canal.

Nuestra Solución

Un número único recibe todos los mensajes de TikTok. El sistema responde automático (saludo), asigna al asesor disponible, y el asesor continúa por WhatsApp personal vía QR. Costo cero: solo pagas lo que uses.

Estructura del Sistema

Base de Datos PostgreSQL
Almacena: conversaciones, contactos, asesores, mensajes, logs. Costo: $0 (tier gratis aguanta 10k+ conversaciones)
Backend API (Node.js)
Endpoint /api/tiktok-conversion recibe webhooks, valida, asigna, responde. Costo: $0 local o $7/mes escalado
WhatsApp API
Envía respuesta automática inicial. Después el asesor usa conexión nativa. Costo: $0 (primeros mensajes en ventana 24h sin costo)
Conexión Nativa WhatsApp
Asesor vincula su WhatsApp personal vía QR. Continuidad sin dashboard web. Costo: $0 (biblioteca open source)
Autenticación JWT
Validación de asesores y contactos. Securiza flujo. Costo: $0 (incluido en backend)
